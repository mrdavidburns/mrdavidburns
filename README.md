# Hi, I'm David Burns 👋

VP of Extended Support at [Lullabot](https://www.lullabot.com/about/david-burns), working from the Philadelphia area.

I've built with Drupal since 2005. I founded Rapid Waters Development, which Lullabot acquired in 2010, and later established Lullabot's support and maintenance department. Today I lead the teams that keep large-scale sites healthy long after launch — in higher education, government, media and entertainment, publishing, and the nonprofit sector.

## What I work on

- 🔧 Long-term support, maintenance, and upgrade strategy for enterprise Drupal platforms
- 🏗️ Site architecture, performance, and platform migrations
- ⚙️ Engineering operations: CI/CD, automation, GitHub administration, and security and cost audits
- 📋 Project and delivery management (Certified ScrumMaster)
